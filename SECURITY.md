# Security policy

## Supported versions

Only the latest `main` branch is currently supported. This project is pre-release and should not be used with production credentials.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory workflow for this repository, or contact the maintainers privately through the repository owner.

Include the affected component, reproduction steps, impact, and a suggested mitigation when available. Please allow reasonable time for investigation before public disclosure.

Never include API keys, access tokens, private source code, or personal data in a report.
